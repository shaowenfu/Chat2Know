# 从 0.1 升级 · Moving from 0.1

0.2 是重写的版本：0.1 的卡片、问句标题、稍后问、考我和复习都不再有，取而代之的是你自己新建的知识导图。0.2 用一个新的数据库，**不导入 0.1 的数据**，也不会改动或删除它。
0.2 is a rebuild: 0.1's cards, question titles, ask-later, quizzes and reviews are gone; maps you create take their place. 0.2 uses a new database, **does not import 0.1's data**, and never changes or deletes it.

- 想保留 0.1 的笔记：**升级前**在 0.1 的侧栏里"导出 ▾ → Markdown"（或 OPML），存成文件。
  To keep your 0.1 notes, export them from 0.1 (*Export ▾ → Markdown* or OPML) **before** updating.
- 模型设置会保留。0.1 里勾选过"学习诊断"的网站会变成 0.2 使用的网站；提问记录在 0.2 默认开启，可以在设置里关掉。
  Model settings carry over. The sites you ticked for 0.1's Learning become 0.2's sites; question recording is on by default in 0.2 and can be turned off in settings.
