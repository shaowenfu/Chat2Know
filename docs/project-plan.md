# Chat2Know v2 方案

2026-10-31 · 代号 `v2`，发布为 0.2.0

本文是仓库内的执行版方案，合并自三份文档：《Chat2Know 重构对齐文档》（为什么重构、保留什么、范围）、《Chat2Know 知识导图设计》（导图结构、生长规则、数据模型）、《Chat2Know 界面设计》画布（8 个画板，https://claude.ai/artifact/YbcpyaNR6aWbC2EvmAAsjr）。三者不一致时以画布和设计文档为准，并在本文更正。v0.1 的方案在 `docs/archive-v0.1/`，只作历史参考。

## 定位与北极星

**一个帮你记笔记的知识导图。** 侧栏是记录工具，不是学习软件。

**北极星：** 导图是否真实反映我学了什么、缺什么；记一条只需一次点击。

衡量导图好不好：

| 指标 | 含义 | 目标 |
| --- | --- | --- |
| 记一条的操作数 | 从看到公式到它进入导图 | 1 次点击 |
| 归位被改动的比例 | 自动放的位置被用户移走的比例 | 越用越低 |
| 导图的可读性 | 学完一门课后，只看导图能否说清学了哪些、缺哪些 | 用户自测通过 |

**三条底线**，加任何功能都用它们判断：

1. **插件不能比它服务的网页更复杂。** 侧栏一屏只做一件事；记一条不超过一次点击。
2. **笔记要比原文更简。** 一个公式进来，就只是一个公式。
3. **插件只问，不往导图里硬塞。** 实线节点要么是用户记的，要么是用户同意插件补的。

## 范围

**做什么**

1. **记到导图。** AI 网站上，公式块旁边有一个 ＋；普通文字选中后按快捷键（Alt+S）或右键。插件自动放到导图里的位置，底部弹一句"已记到 … › …"，可以改位置或撤销。
2. **侧栏导图。** 侧栏只有一个视图：当前学科的导图（大纲式）。顶部切换学科，右上角"展开全页"。
3. **全页导图。** 插件自己的页面：左边是导图，右边是选中节点的公式和出处；另有设置页。
4. **学科大纲。** 第一次在某个学科下记东西时，问一句要不要铺上大纲。大纲以灰色显示，不算笔记。
5. **试探性补短板。** 沿用学习诊断算法，把结果画在导图上；一段对话结束后问一句"要我整理进来吗？"，同意才补。
6. **导出与导入。** JSON、Markdown、OPML；导入 v0.1 的 JSON。

**明确不做**

- 不在插件里问答。提问只在聊天网页里发生。
- 不做复习、考我、间隔重复、掌握程度统计。
- 不让用户为每条笔记选类型、写标题或确认任何东西。
- 不在用户阅读或提问时弹出任何建议。
- 不自动往导图里加实线节点。

## 导图结构

每个学科一张导图；只有两种节点：

- **结构节点**：学科、章、知识点。标题是名词（"矩阵""转置"），不是问句。最多 4 层（学科 + 3 层），第四层只在用户自己拆分时出现。
- **条目**（叶子）：**公式**（存 LaTeX，原样保存）或**结论**（一句话；选中长文字时插件压成一句，原文留在出处里）。条目只挂在结构节点下，下面不再挂东西；每个条目只有一个位置、一个出处。

```text
线性代数                      ← 学科
├─ 矩阵                      ← 章
│  ├─ 转置                   ← 知识点
│  │  ├─ (AB)ᵀ = BᵀAᵀ        ← 条目：公式
│  │  └─ (Aᵀ)ᵀ = A
│  └─ 逆矩阵
│     └─ 可逆当且仅当 det A ≠ 0   ← 条目：结论
└─ 特征值与特征向量
```

| 显示 | 含义 | 怎么来的 | 会不会变 |
| --- | --- | --- | --- |
| 黑色实线 | 用户记下的条目；或其下有用户条目的结构节点 | 点 ＋ 或快捷键 | 不变 |
| 浅蓝虚线 | 插件补充的条目，用户同意过 | 补短板时点了"整理进来" | 用户自己记下同一条时合并成黑色 |
| 灰色虚线 | 大纲里有、还没学到的结构节点 | 铺大纲 | 下面有了条目就变黑 |
| 橙色描边 | 可能是短板（只在结构节点上） | 学习诊断信号 | 补全、测试通过或点"不用"时去掉 |

"是不是灰色"不存储：结构节点及其子孙里没有非 outline 的条目时显示为灰色。导出默认不含灰色节点。

## 生长规则一：用户记录与自动归位

1. **立即入库。** 点击后 1 秒内出现在导图里，不等模型。暂存位置：同一段对话里上一条放在哪个知识点就先放那里；没有就放学科下的"待归位"分组。
2. **去重。** LaTeX 规范化后相同，或向量相似度高于 0.95，不新增，提示"已在 矩阵 › 转置 中"，给"仍然添加"。
3. **找候选位置。** 知识点的向量由"路径 + 标题 + 其下若干条目"组成；灰色大纲节点也是候选。
4. **模型定位置。** 一次调用：判断学科、在候选里选位置或新建知识点、把长文字压成一句（公式不压）。输入：条目内容、选区前后几句、候选路径、整个学科的结构（只有标题）、最近的归位示例；输出严格校验的 JSON。
5. **移入并提示。** 底部提示"已记到 线性代数 › 矩阵 › 转置"，4 秒后消失，带"改位置"和"撤销"。
6. **改位置。** 小选择器：另外 3 个候选、搜索、"新建知识点"；也可以在导图里拖动。
7. **归位示例。** 用户改过的位置记为（条目，最终路径），最近 20 条作为模型的示例；也是"归位被改动的比例"的数据来源。

**没配置模型时：** 有嵌入模型就放到向量最接近的知识点；什么都没有就留在"待归位"，用户自己拖。记录永远不依赖模型。

## 生长规则二：插件补充

| | 铺大纲 | 补短板 |
| --- | --- | --- |
| 什么时候问 | 在一个新学科下记下第一条之后 | 一段对话结束后（该标签页 10 分钟没有新提问、被关闭，或下次打开侧栏时） |
| 问什么 | "要我铺上线性代数的大纲吗？" | "你是不是不太熟悉矩阵的运算规则？要我整理进来吗？" |
| 预览 | 大纲的章和知识点，标出已记的那条在哪 | 将要加入的公式和结论，可逐条取消 |
| 依据 | 模型生成的标准大纲；或用户粘贴的教材目录 | 用户自己发出的提问（反复、降级、绕圈三类信号） |
| 选项 | 铺上大纲 / 按我的教材 / 不用 | 整理进来 / 出道题试试 / 不用 / 看看我问过的 |
| 同意后 | 加入灰色结构节点，不加任何条目 | 加入浅蓝条目；该知识点的橙色标记去掉 |
| 频率上限 | 每个学科只问一次 | 每天最多一次；"不用"后这一块 30 天内不再问 |

- 大纲只有结构（章和知识点，最多 3 层），不生成公式或结论。已记的条目重新归位到大纲里，归不进去的保持原位。
- **大纲兼作学习诊断的概念表**：提问的标签直接指向导图的知识点节点，不再有独立的概念表。
- 补短板先在导图上静默加橙色描边，只在合适时机提问；同时只问一个（能解释最多提问的那个）；整理的内容一般不超过 8 条，用户已有的不重复。
- "出道题试试"：一道题，用户自己答，模型判；答对去掉橙色、30 天不再提；答错再问一次"要整理进来吗？"。不计分、不排复习。
- 插件永远不：在阅读或提问时弹东西；未经同意加条目；自动删除、合并或移动用户的条目。

## 用户对导图的编辑

| 操作 | 侧栏 | 全页 |
| --- | --- | --- |
| 展开 / 折叠 | 点击 | 点击 |
| 跳回出处 | 点条目 | 右侧详情里点"来自对话" |
| 移动 | 拖动，或右键"移到…" | 拖动 |
| 改文字 | 右键"编辑" | 双击 |
| 新建知识点 / 章 | — | 右键"新建子节点" |
| 合并两个知识点 | — | 拖到另一个上 |
| 删除 | 右键"删除" | 选中后按 Delete |
| 手动添加条目 | — | 在知识点上"添加公式 / 结论"，可直接输入 LaTeX |
| 隐藏大纲 / 短板标记 | — | 顶部开关 |
| 撤销 | Ctrl+Z | Ctrl+Z |

- 软删除，30 天内可在全页"最近删除"里恢复。删除结构节点时，其下条目移到上一层。
- 用户移动的条目记为归位示例；改过文字的条目不再被插件改写。
- 侧栏不弹任何对话框，编辑都在右键菜单里。

## 数据模型

新数据库名 `chat2know-v2`，不在 v0.1 的库上升级。导图只有一张 `nodes` 表：每个节点只有一个父节点和一个出处，所以父节点、顺序和出处直接存在节点上，不另设边表和出处表。仓储层、HLC、oplog、分数索引沿用 v0.1。

```ts
type NodeKind = 'subject' | 'section' | 'item';   // 学科 / 章和知识点 / 条目
type ItemType = 'formula' | 'statement';
type Origin = 'user' | 'plugin' | 'outline';     // 黑色 / 浅蓝 / 灰色

interface MapNode {
  id: string;              // ULID
  subjectId: string;       // 所属学科（学科节点自己的 id 就是它）
  kind: NodeKind;
  parentId?: string;       // 只有学科没有
  order: string;           // 兄弟间的分数索引
  title: string;           // 结构节点的名称；结论条目的那一句话
  itemType?: ItemType;     // 只有 item 有
  latex?: string;          // 公式条目的 LaTeX
  source?: { url; pageTitle; quoteExact; quotePrefix; quoteSuffix; capturedAt };  // 用户记下的条目
  origin: Origin;
  role?: 'unplaced';       // 学科下的"待归位"分组，标题由界面按语言显示
  editedByUser?: boolean;  // 用户改过文字后，插件不再改写
  createdAt: number;
  updatedAt: string;       // HLC
  deletedAt?: number;      // 软删除
}
```

**oplog 与撤销。** 每次导图写操作是一组 oplog 记录（同一个 `group`），每条记下节点写之前和之后的整行。撤销一组 = 把组里的节点恢复成写之前的样子；之后又被别的操作改过的节点保持现状。撤销本身也记入 oplog，不能再被撤销。"恢复已删除"就是撤销那次删除。

| 辅助表 | 字段 | 用途 |
| --- | --- | --- |
| `placements` | 条目 id、插件给的路径、最终路径、是否被用户改过 | 归位示例与归位准确率 |
| `gaps` | 知识点 id、证据提问 id、信号、状态（疑似 / 已问 / 已补 / 已否定）、冷却到期时间 | 橙色标记与频率控制 |
| `asks`、`askTags`、`prereqEdges` | 沿用 v0.1；`askTags` 和 `prereqEdges` 直接指向 `section` 节点 | 提问记录与学习诊断 |
| `embeddings` | 沿用 | 节点向量缓存 |

不存：问句标题、掌握要求、复习记录、临时区、偏好、"是否灰色"。

## 已定的技术决定

- 记笔记和记录提问共用一次按站点授权、一个常驻脚本；"也记录我的提问"是设置里的独立开关，关闭时脚本不挂提问监听。
- 公式块的 ＋ 用通用规则识别（KaTeX / MathJax / LaTeX 属性，与 `src/capture/markdown.ts` 相同），只放在独立成行的公式块旁；行内公式靠选中 + 快捷键。哪个站点快照不过，再在 `sites.ts` 里补该站点的规则。
- 全页导图第一版是大纲式树 + 右侧详情（与侧栏共用树组件）；可拖动的横向导图在 R4 里做一次小型对比（手写布局 vs 现成库）再定。
- v0.1 迁移只迁"知识"卡片：正文含公式块的变公式条目，否则用陈述精华变结论条目；问句标题丢弃，出处保留；迁入的条目走自动归位（无模型时进"待归位"）。
- 待定问题的默认值（产品负责人可改）："另见"不做，每个条目只放一处；不同学科是不同的导图；结论一句话、约 40 字以内，可切换为"保留原文"。

## 未来：全页里的学习功能

侧栏永远是记录工具。学习功能（对子树"讲给我听"、按知识点出题、一章生成一页公式卡）只在全页里做，等 0.2.0 稳定后再做；v0.1 的实现可从 `v0.1.0` 标签取回，前提是不增加侧栏和记录动作的复杂度。全页是插件自带页面（`chrome-extension://<id>/map.html`），不需要服务器和账号。
