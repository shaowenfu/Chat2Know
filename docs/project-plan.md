## 定位与北极星

**一个帮你记笔记的知识导图，加一个提问教练。** 侧栏记录并展示导图；插件就选中的内容回答简短的问题，发现用户卡住时提醒，用户要时就提问写一份分析。它不是通用聊天软件，也不是出题打分的老师。

**北极星：** 导图是否真实反映我学了什么、缺什么；记一条是否只需一次点击；卡住时是否更快走出来。

| 指标 | 含义 | 目标 |
| --- | --- | --- |
| 记一条的操作数 | 从选中到它进入导图 | 1 次点击 |
| 归位被改动的比例 | 自动放的位置被用户移走的比例 | 越用越低 |
| 导图的可读性 | 学完一门课后，只看导图能否说清学了哪些、缺哪些 | 用户自测通过 |
| 卡住提醒的准确度 | 人工标注的提问序列上"卡没卡住"的判断 | 评测集记录（`tests/eval/data/stuck.json`） |

**三条底线**，加任何功能都用它们判断：

1. **插件不能比它服务的网页更复杂。** 侧栏一屏只做一件事；记一条不超过一次点击。
2. **笔记要比原文更简，除非用户保护它。** 记下的话压成一句，公式进来就只是公式；**保护的原文**一字不改，只有用户能编辑。
3. **插件只问，不往导图里硬塞。** 实线节点要么是用户记的，要么是用户同意插件补的；插件不新建、不切换导图。

## 范围

**做什么**

1. **用户新建并打开导图。** 一门课或一个主题一张；记下的内容都进打开的那张，直到用户打开另一张。没起名的导图按第一批内容命名一次；用户起的名字永不改。
2. **选中浮层：记下 / 保护原文 / 提问。** 勾选的 AI 网站上选中文字后出现；公式块旁也有 ＋；其他网页用 Alt+S 或右键。点"记下"后浮层变成一个小输入框，可以写一句要求（如"保留表格里的公式"），直接回车就按默认压成一句。记下的内容立即入库，再自动归位，底部提示"已记到 … › …"，可以改位置或撤销。
3. **浮窗提问。** 就选中的内容问一个小问题，流式回答，可以追问；对话不保存，有用的回答记到导图或保护原文。
4. **侧栏导图与全页导图。** 侧栏是当前导图（大纲式），可以像思维导图一样编辑；全页有导图、提问和设置三页。
5. **大纲。** 导图有了名字和第一条内容后，问一次要不要铺上大纲（灰色，不算笔记）。
6. **卡住时的引导。** 提问记入发问时打开的导图；每张导图每满 5 条新提问，模型按顺序读它最近 30 条提问，判断是否在绕圈子、被前面的知识点挡住、问不到点子上或不会组织问题。是的话侧栏出一张引导卡（可能卡在哪、先弄清什么、一个可复制的更好问法），点名的知识点描橙。
7. **提问记录与分析报告。** 全页"提问"页列出所有提问（搜索、按导图筛选、删除）；用户点"生成新报告"时，模型按这张导图的提问写一份 Markdown 文字分析，保存并可看历史。不打分。
8. **导出与导入。** JSON（无损）、Markdown、OPML；导入 JSON 导出文件。不导入 0.1 的数据。

**明确不做**

- 不做通用聊天。插件里的提问只从页面上的选中内容发起，对话不保存。
- 不做复习、考我、间隔重复、分数和掌握程度。报告是文字分析，只在用户要求时生成。
- 不让用户为每条笔记选类型、写标题或确认任何东西。
- 用户没动作时聊天页面上什么都不出现：浮层只在选中后出现，卡住引导只在侧栏。
- 不自动往导图里加实线节点；不新建、改名或切换导图。

## 导图结构

用户新建的每张导图一棵树；只有两种节点：

- **结构节点**：学科、章、知识点。标题是名词（"矩阵""转置"），不是问句。最多 4 层（学科 + 3 层），第四层只在用户自己拆分时出现。
- **条目**（叶子）：**公式**（存 LaTeX，原样保存）、**结论**（一句话；选中长文字时插件压成一句，原文留在出处里）或**原文**（用户保护的原话，一字不改，模型只决定位置，紫色外框、衬线字）。条目只挂在结构节点下，下面不再挂东西；每个条目只有一个位置、一个出处，通过条目旁的 ↗ 跳回对话。

```text
线性代数                      ← 学科
├─ 矩阵                      ← 章
│  ├─ 转置                   ← 知识点
│  │  ├─ (AB)ᵀ = BᵀAᵀ        ← 条目：公式
│  │  └─ (Aᵀ)ᵀ = A
│  └─ 逆矩阵
│     └─ 可逆当且仅当 det A ≠ 0   ← 条目：结论
└─ 特征值与特征向量
```

| 显示 | 含义 | 怎么来的 | 会不会变 |
| --- | --- | --- | --- |
| 黑色实线 | 用户记下的条目；或其下有用户条目的结构节点 | 点 ＋ 或快捷键 | 不变 |
| 浅蓝虚线 | 插件补充的条目，用户同意过 | 用户同意后由插件加入（0.2 没有这样的入口） | 用户自己记下同一条时合并成黑色 |
| 灰色虚线 | 大纲里有、还没学到的结构节点 | 铺大纲 | 下面有了条目就变黑 |
| 橙色描边 | 可能卡住的地方（只在结构节点上） | 每 5 条新提问的检查 | 下一次检查没看到卡住、点"不用"或删掉该知识点时去掉 |

"是不是灰色"不存储：结构节点及其子孙里没有非 outline 的条目时显示为灰色。导出默认不含灰色节点。

## 生长规则一：用户记录与自动归位

1. **立即入库。** 点击后 1 秒内出现在打开的导图里，不等模型。暂存位置：同一段对话里上一条放在哪个知识点就先放那里；没有就放这张导图的"待归位"分组。没有打开的导图时不入库，提示里给"新建导图并记下"。
2. **去重。** 在打开的导图里：公式的 LaTeX 规范化后相同、结论的文字（忽略大小写和空白）相同、原文逐字相同时不新增，提示"已在 矩阵 › 转置 中"，给"仍然添加"。
3. **找候选位置。** 知识点的向量由"路径 + 标题 + 其下若干条目"组成；灰色大纲节点也是候选。
4. **模型定位置。** 一次调用，只在打开的导图里：在候选里选位置或新建章和知识点、把长文字压成一句（公式和原文不压），导图没名字时顺带起名。输入：条目内容、选区前后几个字、候选路径、这张导图的结构（只有标题）、用户在这张导图里最近改过的归位；输出严格校验的 JSON。
5. **移入并提示。** 底部提示"已记到 线性代数 › 矩阵 › 转置"，4 秒后消失，带"改位置"和"撤销"。
6. **改位置。** 小选择器：另外 3 个候选、搜索、"新建知识点"；也可以在导图里拖动。
7. **归位示例。** 用户改过的位置记为（条目，最终路径），最近 20 条作为模型的示例；也是"归位被改动的比例"的数据来源。

**没配置模型时：** 有嵌入模型就放到向量最接近的知识点；什么都没有就留在"待归位"，用户自己拖。记录永远不依赖模型。

## 生长规则二：插件补充

| | 铺大纲 |
| --- | --- |
| 什么时候问 | 导图有了名字和第一条内容之后 |
| 问什么 | "要我铺上线性代数的大纲吗？" |
| 预览 | 大纲的章和知识点，标出已记的那条在哪 |
| 依据 | 模型生成的标准大纲；或用户粘贴的教材目录 |
| 选项 | 铺上大纲 / 按我的教材 / 不用 |
| 同意后 | 加入灰色结构节点，不加任何条目 |
| 频率上限 | 每张导图只问一次（改名后按新名字重新提议） |

- 大纲只有结构（章和知识点，最多 3 层），不生成公式或结论。已记的条目重新归位到大纲里，归不进去的保持原位。

**卡住时的引导（0.2 起替换"补短板"）。** 每张导图每满 5 条新提问检查一次：模型读最近 30 条（按时间、按对话分段、标出浮窗里问的），以及导图的知识点。看到绕圈子（circling）、被前面的知识点挡住（stuck）、问不到点子上（offTarget）或不会组织问题（phrasing）时，侧栏顶部出一张引导卡：标题按类型和知识点写成（"好像在「矩阵乘法」这里绕了几圈"），说明两三句，"可以这样问"给一个可复制的问法，"看看我问过的"展开证据提问，"不用"收起并让这张导图当天不再提。点名的知识点描橙，直到下一次检查没看到卡住。不打分、不出题、不往导图里加东西。

- 插件永远不：在阅读或提问时弹东西；未经同意加条目；自动删除、合并或移动用户的条目。

- 软删除，30 天内可在全页"最近删除"里恢复。删除结构节点时，其下条目移到上一层。
- 用户移动的条目记为归位示例；改过文字的条目不再被插件改写。
- 侧栏不弹任何对话框，编辑在原地完成（双击、键盘、右键菜单）。
- 原文条目只有用户能改，插件的归位、压缩都不碰它的文字。

## 数据模型

新数据库名 `chat2know-v2`，不在 v0.1 的库上升级（库内版本：1 初版，2 提问归入导图并换成卡住检查，3 分析报告）。导图只有一张 `nodes` 表：每个节点只有一个父节点和一个出处，所以父节点、顺序和出处直接存在节点上，不另设边表和出处表。仓储层、HLC、oplog、分数索引沿用 v0.1。

```ts
type NodeKind = 'subject' | 'section' | 'item';   // 学科 / 章和知识点 / 条目
type ItemType = 'formula' | 'statement' | 'quote';   // 公式 / 结论 / 原文
type Origin = 'user' | 'plugin' | 'outline';     // 黑色 / 浅蓝 / 灰色

interface MapNode {
  id: string;              // ULID
  subjectId: string;       // 所属导图（导图节点自己的 id 就是它）
  kind: NodeKind;
  parentId?: string;       // 只有学科没有
  order: string;           // 兄弟间的分数索引
  title: string;           // 结构节点的名称；结论条目的那一句话
  itemType?: ItemType;     // 只有 item 有
  latex?: string;          // 公式条目的 LaTeX
  source?: { url; pageTitle; quoteExact; quotePrefix; quoteSuffix; capturedAt };  // 用户记下的条目
  origin: Origin;
  role?: 'unplaced';       // 学科下的"待归位"分组，标题由界面按语言显示
  editedByUser?: boolean;  // 用户改过文字后，插件不再改写
  createdAt: number;
  updatedAt: string;       // HLC
  deletedAt?: number;      // 软删除
}
```

**oplog 与撤销。** 每次导图写操作是一组 oplog 记录（同一个 `group`），每条记下节点写之前和之后的整行。撤销一组 = 把组里的节点恢复成写之前的样子；之后又被别的操作改过的节点保持现状。撤销本身也记入 oplog，不能再被撤销。"恢复已删除"就是撤销那次删除。

| 辅助表 | 字段 | 用途 |
| --- | --- | --- |
| `placements` | 条目 id、插件给的路径、最终路径、是否被用户改过 | 归位示例与归位准确率 |
| `asks` | 提问文字、网站、对话网址、时间、发问时打开的导图、来源（网站 / 浮窗） | 提问记录（只在本地，不进 oplog 和默认导出） |
| `stuckChecks` | 导图、读过的提问、是否卡住、类型、知识点、说明、更好的问法、证据提问、"不用"的时间 | 卡住引导卡与橙色标记 |
| `reports` | 导图、生成时间、Markdown 正文、读过的提问数 | 分析报告与历史版本 |
| `embeddings` | 沿用 | 节点向量缓存 |

不存：问句标题、掌握要求、复习记录、临时区、偏好、"是否灰色"。

## 已定的技术决定

- 记笔记、选中浮层、浮窗提问和记录提问共用一次按站点授权、一个常驻脚本；"也记录我的提问"默认开启，是设置里的独立开关，关闭时脚本不挂提问监听。
- 公式块的 ＋ 用通用规则识别（KaTeX / MathJax / LaTeX 属性，与 `src/capture/markdown.ts` 相同），只放在独立成行的公式块旁；行内公式靠选中 + 快捷键。哪个站点快照不过，再在 `sites.ts` 里补该站点的规则。
- 全页导图第一版是大纲式树 + 右侧详情（与侧栏共用树组件）；可拖动的横向导图在 R4 里做一次小型对比（手写布局 vs 现成库）再定。
- 不迁移 v0.1 的数据（第一轮测试后决定）：0.2 用新数据库，不读也不改 0.1 的库；想保留 0.1 笔记的用户在升级前从 0.1 导出。
- 待定问题的默认值（产品负责人可改）："另见"不做，每个条目只放一处；结论一句话、约 40 字以内；要保留原话时用"保护原文"。
- 模型的 JSON 回复严格校验，不合格就报错，不修补；温度用服务商默认值（有些兼容 OpenAI 的推理模型不接受温度参数）。
- 浮窗回答和分析报告里的公式用 KaTeX 排版（页面上用 MathML，不依赖页面的字体和样式）；报告用 `marked` 解析、DOMPurify 清洗，只留排版标签和 http(s) 链接。

## 未来：全页里的学习功能

侧栏永远是记录工具。更多学习功能（对子树"讲给我听"、一章生成一页公式卡）只在全页里做，等 0.2.0 稳定后再看，且不能违反"不出题、不打分"；v0.1 的实现可从 `v0.1.0` 标签取回，前提是不增加侧栏和记录动作的复杂度。全页是插件自带页面（`chrome-extension://<id>/map.html`），不需要服务器和账号。
